# Repo para EIEC - DevOps - UNIR

Este repositorio nos servirá para demostrar el uso de Git en la asignatura de EIEC y muchas cosas mas.

\---

Los comandos del Makefile funcionarán en Linux y MacOS. En caso de usar Windows, necesitarás adaptarlos o ejecutarlos en una máquina virtual Linux.

## Ejecución

python3 main.py <filename> <dup>
filename: **ruta** al fichero que contiene la lista de palabras, una por línea
dup: **yes|no**, yes para eliminar palabras duplicadas, no para mantener la lista



\## Ejemplo de ejecución



Este proyecto permite ordenar una lista de palabras utilizando Python.



\### Ejecución local



```bash

python main.py --help




\## Documentación de ejecución del proyecto



\### Descripción

Este proyecto forma parte de la actividad de Entornos de Integración y Entrega Continua de UNIR.



La aplicación está desarrollada en Python y permite trabajar con una lista de palabras para ordenarlas.



\### Archivos del proyecto

\- `main.py`: contiene el código principal de la aplicación.

\- `Makefile`: contiene instrucciones para facilitar la ejecución.

\- `README.md`: contiene la documentación del proyecto.



\### Ejecución del programa

Para ejecutar la aplicación es necesario disponer de Python instalado en el equipo.



Desde la terminal, situarse en la carpeta del proyecto y consultar las opciones disponibles:



```bash

python main.py --help

```



\### Trabajo colaborativo con GitHub

Este proyecto se utiliza para practicar el trabajo colaborativo mediante GitHub.



Cada integrante realiza cambios en una rama independiente y propone su integración a través de una pull request.
